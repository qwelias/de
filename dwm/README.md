heavily based on [bakkeby/dwm-flexipatch](github.com/bakkeby/dwm-flexipatch)
and hacked in various places
also put everything in the same dwm.c for the sake of my sanity

some keys:
- Sup+e           = switch tag right
- Sup+LShift+e    = move window tag right
- Sup+q           = switch tag left
- Sup+LShift+q    = move window tag left
- Sup+d           = switch window right
- Sup+a           = switch window left
- Sup+s           = switch floating
- Sup+c           = close window
- Sup+LShift+c    = close wm
- Sup             = switch layout
- Sup+Tab         = move window to top

for the rest of keys and mouse buttons see `keys[]` and `buttons[]` in `dwm.c`
